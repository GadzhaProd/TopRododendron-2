# Top Rhododendrons — макеты главной страницы (фаза 1)

Три направления дизайна главной страницы для семейного питомника рододендронов Top Rhododendrons (Otterlo, Veluwe). Статический HTML/CSS без сборки; минимальный vanilla JS (мобильное меню, подмена видео при `prefers-reduced-motion`, смена картинки в каталоге направления A). Шрифты — только Google Fonts.

Открыть: `mockup/index.html` — обзорная страница со ссылками на три макета.

| Папка | Направление | Позиционирование |
|---|---|---|
| `a/` | **Het Veld** — каталог питомника | **Сохраняет** позиционирование из PRODUCT.md |
| `b/` | **Zeven Kleuren** — семь цветов, одно поле | Свободная концепция |
| `c/` | **Het Seizoen** — журнал о сезоне | Свободная концепция (ближе к исходному регистру, но подача переосмыслена) |

`assets/` — оптимизированные копии фото (≤ 1800 px, JPEG), уменьшенные варианты `-sm` (≤ 800 px), перекодированное хиро-видео (1,5 МБ) и постер-кадр. Оригиналы (17–22 МБ) не включены.
`screenshots/` — полностраничные скриншоты каждого направления на 1440 и 390 px.

## Что не повторяется из старого сайта

Старый сайт: кремово-зелёная палитра с маджента-акцентом, Cormorant Garamond + DM Sans, полноэкранное видео по центру с градиентом и огромным заголовком, скруглённые карточки, порядок секций hero → trust bar → карточки → about → календарь → FAQ → контакт. Ничего из этого не использовано: другие палитры, другие шрифты, другие хиро, другая структура и другие компоненты.

## Направление A — «Het Veld» (сохраняет позиционирование)

**Концепция.** Каталог производителя в духе винодельческого домена: тихая уверенность, документальный тон, факты вместо прилагательных. Страница устроена как линованный реестр с нумерованными главами (01 — De kwekerij … 06 — Contact).

- **Типографика:** Newsreader (заголовки и текст, с курсивом) + IBM Plex Mono (подписи, навигация, данные). Основной текст 19 px — для аудитории 45–70.
- **Палитра:** бумага `#f3eee4`, торф `#2b221c`, чернила `#1f1a16`, вересково-лиловый акцент `#5e4674` (отсылка к вересковым пустошам Veluwe и к цвету рододендрона).
- **Хиро:** разворот — слева заголовок «Rhododendrons van de Veluwe.» и две «двери» (voor uw tuin / voor uw project), справа вертикальное видео как колонна на всю высоту с подписью.
- **Ключевые идеи:** строка фактов как строка реестра; раздел о питомнике с портретом Gert Top и четырьмя обещаниями; ассортимент как список-каталог с большим «липким» фото, меняющимся при наведении/фокусе; календарь цветения и посадки; тёмный блок groothandel с четырьмя шагами и таблицей размеров; plantgids; контакт-карточка.

## Направление B — «Zeven Kleuren» (свободная)

**Концепция.** Питомник как «книга цветов»: весь сайт организован вокруг семи сортов и их реальных оттенков. Плакатный, честный, без распродажного шума — крупный шрифт, мало слов, плоские цветовые поля, толстые 2 px линии.

- **Типографика:** Bricolage Grotesque (узкий, прописной, 700–800) + Instrument Sans.
- **Палитра:** чернила `#16120f`, тёплый белый `#faf7f2`, и семь цветов сортов, приведённые к контрасту AA: рood `#b3202f`, roze `#be3f77`, lila `#b07cc8`, lavendel `#7a4fa6`, lichtroze `#e9a9c9`, violet `#5b3f8c`, crème `#f3eee6`.
- **Хиро:** триптих — заголовок «Zeven kleuren. Eén veld.» / вертикальное видео / две цветные «двери» (красная — для сада, фиолетовая — groothandel).
- **Ключевые идеи:** бегущая строка с фактами (статична при reduced-motion); ассортимент как семь полос-свотчей с фото, периодом цветения и ценой; тёмный блок садовода с цитатой и четырьмя обещаниями; полноэкранное фото поля «10.000 planten op stam»; фиолетовый блок «Voor de vakman» с шагами и условиями; plantgids на нативных `<details>`; крупный тёмный контакт-футер.

## Направление C — «Het Seizoen» (свободная)

**Концепция.** Главная как номер журнала о сезоне на питомнике. Обложка «Otterlo, mei.», оглавление и шесть глав: I De grond, II De kweker, III Zeven soorten, IV Het jaar, V Voor professionals, VI Bezoek. Фотография и сторителлинг на первом плане; коммерция — спокойными ссылками внутри глав.

- **Типографика:** Bodoni Moda (дисплейный, курсив для акцентов) + Work Sans 300/500.
- **Палитра:** ночь `#121214`, тёплый белый `#f2efe9`, янтарь `#d9a86c` (свет «золотого часа» из видео), лиловый `#b9a4d6`.
- **Хиро:** журнальная обложка — гигантский курсивный заголовок, под ним вертикальное видео как обложечное фото, слева аннотация номера, справа две «двери».
- **Ключевые идеи:** оглавление с римскими номерами; глава о почве с буквицей и колофоном фактов; портрет садовода с крупной цитатой; горизонтальная галерея семи сортов со scroll-snap; «год рододендрона» — линейка месяцев и четыре момента (посадка, цветение, обрезка, посадка); блок для профессионалов; визит и колофон.

## Общее для всех направлений

- Только реальные факты и тексты из старого репозитория (сокращены/отредактированы). Без выдуманных отзывов, цифр, наград; цены — из `lib/products.ts` («vanaf € … за 40–60 см»).
- Обе аудитории на одной странице: путь B2C (ассортимент → bestellen) и путь B2B (groothandel → offerte / WhatsApp / телефон).
- Адаптив 1440 → 390 без горизонтальной прокрутки; контраст WCAG AA; `prefers-reduced-motion` отключает анимации и подменяет видео постером; видимый фокус; skip-link; `alt` на фото.
- Мобильная плавающая кнопка WhatsApp.

## Открытые вопросы владельцу

1. **Видео.** Хиро-видео вертикальное и, судя по водяному знаку «Veo», сгенерировано ИИ. В макетах оно используется как вертикальная колонна с обрезанным знаком. Для продакшена стоит снять настоящее видео на поле в мае — PRODUCT.md называет ИИ-картинки «фатальными» для бренда.
2. **Логотип.** В старом репозитории его нет (`icon.svg` — заглушка шаблона). В каждом направлении — свой текстовый знак; нужен ли графический логотип?
3. **Отзывы и примеры проектов** со старого сайта не использованы: их подлинность не подтверждена.
4. Горизонтальные фото сортов (крупные планы) частично квадратные 1024 px — для продакшена желательны съёмки в едином формате.

## Следующая фаза

После выбора направления оно будет расширено на остальные страницы в той же системе токенов:

- **Assortiment** — каталог с фильтрами (цвет, высота, место), размеры и цены.
- **Страница сорта** — галерея, kenmerken, выбор размера, добавление в корзину, tuinturf.
- **Groothandel** — целевые группы, процесс offerte, таблица размеров/наличия, условия (factuur 30 dagen, btw verlegd, plantpaspoort), форма.
- **Plantgids** — советы по посадке, почве, обрезке, сравнение сортов, календарь.
- Корзина/оформление заказа, контактная форма, voorwaarden/privacy, компоненты (header, footer, offerte-modal, WhatsApp).
