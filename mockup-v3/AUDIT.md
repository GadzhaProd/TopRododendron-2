# Аудит макета v3 «Kwekerij» — Top Rhododendrons

Независимый аудит дизайна и фронтенда. Файлы проекта не изменялись.
Объект: `mockup-v3/dist/` (5 страниц), исходники `mockup-v3/src/`, README v3. Сравнение со старым сайтом `/home/user/rhododendrons`, раундом 1 (`mockup/a`, ветка `mockup/homepage-directions`) и концептом C «Veld» (`mockup-v2/dist/c`).

Как проверялось: `dist/` раздавался собственным сервером со строгим CSP из брифа и поддержкой Range для mp4. Chromium/Playwright, 7 вьюпортов (360×640 … 1440×900). Страницы прокручивались медленно, снимался каждый экран (во вьюпорт, не full-page). Проверены взаимодействия: меню, фильтры и сортировка, хэш-роутинг товара, галерея и лайтбокс, размер, количество, корзина, формы, диалоги, FAQ, клавиатура, reduced-motion. Контраст считался попиксельно: текст делался прозрачным и сравнивался с реальным фоном под ним, для видео — на нескольких кадрах. Отдельно измерен вес страниц, кадры видео проверены на водяной знак.
Все доказательства лежат в этой папке. `sheet-*` — листы экранов, `ev-*` — отдельные доказательства, `compare-r1-c-v3-*` — сравнение трёх раундов. Цифры в `metrics.txt`, `contrast.txt` и `weight.txt`.

## 1. Итог

**Итоговая оценка.** Функционально и по контенту v3 — лучший раунд из трёх. Это первый макет, который реально похож на сайт питомника:
- есть страница сорта с выбором размера и рабочая корзина;
- есть plantgids со сравнением, календарём и 7 советами;
- B2B вынесен в отдельный канал;
- цены сходятся со старым сайтом;
- строгий CSP не ломает ни одной страницы: 0 ошибок консоли, 0 неудачных запросов, шрифты грузятся, видео играет;
- водяного знака Veo нет ни в одном кадре обеих нарезок.

Визуально v3 **не стал шагом вперёд от C**. Он сделал шаг назад, к отвергнутому раунду 1, и почти дословно воспроизводит штамп «AI-premium».

| Признак | Раунд 1 (A) — отвергнут | C «Veld» — ближе всего | v3 |
|---|---|---|---|
| Фон | бумага `#f3eee4` | тёплый камень | бумага `#f4f1ea` (≈ тот же цвет) |
| Шрифт заголовков | **Newsreader** (serif) | Manrope (гротеск) | **Newsreader** (тот же serif, что в раунде 1) |
| Надзаголовки | моно-капс, трекинг | мелкий капс | 12 px капс в винном цвете над каждой секцией |
| Структура списков | волосяные линии, нумерация 01–04 | карточки | волосяные линии, нумерация 01–07 |
| Заголовок витрины | «Zeven soorten. Alle winterhard, alle van eigen veld.» | «Zeven soorten. Alle winterhard.» | **«Zeven soorten. Alle winterhard, alle van eigen veld.»** — слово в слово из раунда 1 |
| Hero | видео справа, текст на бумаге | видео на весь экран, текст поверх | видео на весь экран (от C) + матовая бумажная шапка |

Доказательство: `compare-r1-c-v3-1440.jpg`, `compare-r1-c-v3-390.jpg`. Верхний ряд — раунд 1, средний — C, нижний — v3.

Получилась компоновка C в «коже» раунда 1. Набор «тёплый кремовый фон + оптический serif + мелкие трекингованные надзаголовки + волосяные линии + нумерация + заголовки с точкой» — ровно то, что сейчас читается как генерик-AI-премиум. Ничего специфичного для питомника в этом визуальном языке нет. Сам README называет решение «каталогом производителя». Владелец уже отклонил этот регистр словами «шаблонно, скучно, примитивно, не премиально».

Где v3 действительно лучше C:
- глубина продукта: страница сорта, корзина, plantgids, календарь цветения в реальных цветах соцветий, B2B-поток с формой, диалогом и контактным лицом;
- честные пометки «Demo»;
- собственный SVG-знак.

Всё это стоит сохранить.

**Рекомендация по направлению.** Сохранить информационную архитектуру и компоненты v3. Визуальный язык вернуть к C и усилить:
- один характерный гротеск (как Manrope в C) или пара без «книжного» serif;
- более крупная фотография поля и соцветий;
- тёмный мох/ночь как опорный цвет вместо бумаги;
- надзаголовок 1–2 раза на страницу, а не над каждой секцией;
- меньше нумерации и волосяных линий.

Отличие должно идти от фото, цвета соцветий и конкретики питомника, а не от типографских штампов.

**Сводка по найденному:** критично — 2, важно — 9, желательно — 15.

Главное:
1. Лайтбокс на странице сорта нельзя закрыть касанием или кликом: страница «замораживается» вместе с ним. На телефоне пользователь застревает.
2. Визуальный регресс к раунду 1 и штамп «AI-premium» (см. таблицу выше).
3. В режиме артефакта (каждая страница отдельно) ссылки на «себя» с именем файла (`index.html#contact`, `product.html#slug`) не работают. Страница товара показывает только Nova Zembla.
4. Белый текст на белых цветах в блоке «Voor professionals»: контраст около 2:1. Надзаголовок и лид hero местами ниже AA.
5. Плавающая кнопка WhatsApp на groothandel перекрывает текст, подписи формы, ссылки футера и CTA.
6. Страница сорта: на телефоне цена и «In winkelwagen» появляются только через ~2 экрана, на ноутбуке — ниже первого экрана.
