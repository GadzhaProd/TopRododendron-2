# Top Rhododendrons — макеты, версия 2 (три премиальные концепции)

Ответ на обратную связь владельца по v1: «шаблонно, не премиально, нет доверия». Три концепции, построенные с нуля на React + Vite + Tailwind из компонентов **21st.dev**, адаптированных под бренд. У каждой концепции — **главная для частных покупателей** (видео на весь первый экран) и **отдельная страница Groothandel (B2B)** со своим сценарием: offerte-форма, WhatsApp, телефон. Навигация ведёт туда и обратно.

Раунд 3: все 43 замечания независимого аудита закрыты или обоснованно отклонены — см. `AUDIT.md`, раздел «Что исправлено».

**Открыть:** `dist/index.html` — обзорный хаб (RU) со ссылками на 6 страниц. Страницы собраны как самодостаточные HTML-файлы (скрипт и стили встроены, медиа в `dist/assets/`) и открываются прямо с диска двойным кликом, а также как опубликованный артефакт.

**Видео-превью для телефона и компьютера:** `previews/` — 12 роликов (по два на страницу): `A-Maison-glavnaya-telefon.mp4`, `A-Maison-opt-telefon.mp4`, `A-Maison-glavnaya-kompyuter.mp4` … (`glavnaya` = главная, `opt` = groothandel). Плавная прокрутка сверху вниз с паузами на ключевых секциях, 20–30 с.

## Структура

```
mockup-v2/
  index.html, a/, b/, c/        — HTML-входы (хаб + 6 страниц; фавиконы, OG, описания)
  build-single.mjs              — сборка каждой страницы в один HTML-файл (npm run build)
  src/components/ui/            — адаптированные компоненты 21st.dev + product-sheet (экран сорта)
  src/concepts/{a,b,c}/         — тема (theme.css), логотип и общие элементы (shared.tsx), Home.tsx, Groothandel.tsx
  src/data/content.ts           — единственный источник фактов и текстов (из старого сайта)
  src/lib/store.ts              — демо-хранилища: открытый экран сорта, счётчик корзины
  src/assets/                   — фото в WebP (полные ≤1800 px + -sm ≤900 px для srcset), два варианта видео + постеры
  dist/                         — статическая сборка (всё локально; Google Fonts по ссылке)
  screenshots/                  — скриншоты 7 страниц на 1440 и 390 (полная прокрутка + первый экран)
  previews/                     — видео-превью (телефон 390×844 @2x и компьютер 1440×900)
  AUDIT.md                      — отчёт аудита + что исправлено
```

Команды: `npm install`, `npm run build` (→ `dist/`), `npm run dev`, `npm run build:modules` (обычная ES-module сборка).

## Видео-хиро

Исходник вертикальный (720×1280), с водяным знаком «Veo» внизу справа.
- **Десктоп** `hero-desktop.mp4`: полоса 3:2 ниже лица (y 380–860: кусты + руки с цветами; лицо не попадает ни в один кадр цикла), апскейл Lanczos только до 1440×960, CRF 27 → 1,8 МБ.
- **Мобильный** `hero-mobile.mp4`: обрезан низ (100 px) с водяным знаком; показывается как вертикальный ролик, 1,5 МБ.
- Вариант выбирается по ширине экрана; при `prefers-reduced-motion` вместо видео — постер-кадр. Шапка — полупрозрачная матовая полоса с первого пикселя, поэтому логотип и меню читаются над любым кадром (≥ 4,5 : 1).

## Концепция A — «Maison» (светлая галерея)

Регистр дорогого «дома» (парфюмерия, вино): слоновая кость `#f7f5f0`, графит `#151412`, сливовый акцент `#3a2430`, латунная линия `#b59c74`; прямые углы, тонкие линии, много воздуха. Шрифты **Instrument Serif** + **Geist**. Логотип «Truss»: семь лепестков в кольце + серифный wordmark (подпись «Kwekerij · Otterlo · sinds 2001» только в футере).
Главная: видео-хиро с заголовком слева и строкой фактов → утверждение «Wij kweken rhododendrons…» → ассортимент с «липким» фото и шкалой 1–7 → портрет Герта Топа с четырьмя нумерованными обещаниями → фото поля + три двери (Advies / Bezoek / Groothandel) → FAQ → контакт на сливовом фоне → компактный футер.
Groothandel: полноэкранное фото поля, факты, три целевые группы, четыре шага, таблица размеров/наличия, партийные цены и сервисы, сливовый блок с offerte-формой и контактным лицом, FAQ.

## Концепция B — «Estate» (шампань и латунь)

Наследие и статус без «костюма»: тёмными остались только hero, полоса фактов, фото поля, блок offerte и футер (`#0f1412`); контент — шампань `#f3eee4`, латунь `#6f5a30` (текст, AA) / `#cdb17c` (линии); симметричная центрированная композиция, рамки-outline вокруг фото. Шрифты **Marcellus** (обычным регистром) + **Figtree**. Логотип — печать «TR» в двойном кольце; полная версия с кольцевой надписью «TOP RHODODENDRONS · OTTERLO · 2001».
Главная: видео-хиро с печатью → полоса фактов → утверждение → горизонтальная галерея семи сортов, закреплённая под шапкой (на мобильном — свайп) → портрет садовода в рамке с цитатой и обещаниями → фото поля → сплит-панели «для сада / для профессионалов» → FAQ → «Bezoek» с контактами → футер.
Groothandel: печать, заголовок обычным регистром, факты, карточки проектов, шаги, voorraad, тёмный блок offerte-формы, FAQ.

## Концепция C — «Veld» (современный минимализм)

Тёплый камень `#f1efea`, чернила `#141413`, олива `#3f4a37` для CTA; большие скруглённые фотоблоки (28 px), кнопки-пилюли, поля формы 14 px, капсульная навигация при прокрутке. Один гротеск **Manrope**. Логотип — геометрический лист-монограмма + «Top Rhododendrons» с заглавных и подпись «Kwekerij Otterlo · sinds 2001».
Главная: видео-хиро «Rhododendrons die aanslaan. Met aangroeigarantie.» → «Vier redenen» (фото поля + четыре обещания списком) → карточки семи сортов с ценой и tuinturf-баннером → портрет садовода с цитатой → сплит-CTA «для сада / для профессионалов» → FAQ → зелёный контакт-блок → футер.
Groothandel: скруглённый хиро-блок с пилюлями и строкой фактов, проекты, шаги, таблица, оливковый блок с offerte-формой, FAQ.

## Общее для всех концепций

- **Путь покупки.** Клик по сорту открывает экран сорта: две реальные фотографии, характеристики, выбор размера с реальным прайсом (`lib/products.ts`), количество, итог, «In winkelwagen» (демо-корзина со счётчиком в шапке), гарантия и доставка рядом с кнопкой. Ни одной ссылки `#` на страницах нет.
- **Форма offerte**: bedrijf, contactpersoon, e-mail, telefoon, soort, maat, aantal, maand/jaar levering, toelichting; обязательные поля помечены, ошибки на голландском, явная пометка «Demo».
- Только реальные тексты и факты из старого репозитория; отзывы и «примеры проектов» не использованы.
- Доступность: AA-контраст (включая шапку над видео), мобильное меню-диалог (Escape, ловушка фокуса, `inert`), skip-link, двойной контур фокуса, `aria` у аккордеона и диалогов, `prefers-reduced-motion`.
- Проверено Playwright на 360×640, 375×667, 390×844, 768×1024, 1024×768, 1366×768, 1440×900: без горизонтальной прокрутки, без ошибок консоли.

## Открытые вопросы владельцу

1. Какая концепция ближе? Можно комбинировать (например, логотип из одной, структуру из другой).
2. Формулировка гарантии: в старом сайте есть и «wij vervangen kosteloos», и «wij zoeken samen naar een passende oplossing». В макетах использована первая; утвердить одну.
3. WhatsApp: в старом сайте два номера (`31620297849` в шапке, `31318592483` на плавающей кнопке). В макетах — первый. Какой верный?
4. Видео — ИИ-ролик; для продакшена лучше снять настоящее видео поля в мае (горизонтальное и вертикальное). Фото Герта на поле вместо студийного портрета тоже усилит доверие.
5. Графический логотип: три предложения в SVG — выбрать один для доработки.
6. Следующая фаза: настоящие страницы сорта и корзина, ассортимент с фильтрами, plantgids, отправка форм, самохостинг шрифтов.
