# Top Rhododendrons — макеты, версия 2 (три премиальные концепции)

Ответ на обратную связь владельца по v1: «шаблонно, не премиально, нет доверия». Три новых концепции, построенных с нуля на React + Vite + Tailwind из компонентов **21st.dev**, адаптированных под бренд. У каждой концепции — **главная для частных покупателей** (видео на весь первый экран) и **отдельная страница Groothandel (B2B)** со своим сценарием: offerte-форма, WhatsApp, телефон. Навигация ведёт туда и обратно.

**Открыть:** `dist/index.html` — обзорный хаб (RU) со ссылками на 6 страниц. Сборка — ES-модули, поэтому открывать по http(s): как опубликованный артефакт или через любой статический сервер (`npx serve dist`, `python3 -m http.server -d dist`). Двойной клик по файлу с диска не сработает.

## Структура

```
mockup-v2/
  index.html, a/, b/, c/        — HTML-входы (хаб + 6 страниц)
  src/components/ui/            — адаптированные компоненты 21st.dev (см. ниже)
  src/concepts/{a,b,c}/         — тема (theme.css), логотип и общие элементы (shared.tsx), Home.tsx, Groothandel.tsx
  src/data/content.ts           — единственный источник фактов и текстов (из старого сайта)
  src/assets/                   — оптимизированные фото, два варианта видео + постеры
  dist/                         — статическая сборка (base './', всё локально; Google Fonts по ссылке)
  screenshots/                  — скриншоты всех 7 страниц на 1440 и 390 (полная прокрутка + первый экран)
```

Команды: `npm install`, `npm run build` (→ `dist/`), `npm run dev`.

## Видео-хиро

Исходник вертикальный (720×1280), с водяным знаком «Veo» внизу справа.
- **Десктоп** `hero-desktop.mp4`: вырезана горизонтальная полоса 3:2 (кусты + руки с цветами, без лица), апскейл Lanczos до 1620×1080 с лёгкой резкостью; `object-fit: cover`.
- **Мобильный** `hero-mobile.mp4`: обрезан низ (100 px) с водяным знаком; показывается как вертикальный ролик.
- Вариант выбирается по ширине экрана; при `prefers-reduced-motion` вместо видео — постер-кадр. На скриншотах 390 px знака нет.

## Концепция A — «Maison» (светлая галерея)

Регистр дорогого «дома» (парфюмерия, вино): слоновая кость `#f7f5f0`, графит `#151412`, сливовый акцент `#3a2430`, латунная линия `#b59c74`; прямые углы, тонкие линии, много воздуха. Шрифты **Instrument Serif** + **Geist**. Логотип «Truss»: семь лепестков в кольце + серифный wordmark и строка «Kwekerij · Otterlo · 2001».
Главная: видео-хиро с заголовком слева и строкой фактов → утверждение «Wij kweken rhododendrons…» → ассортимент с «липким» фото, которое меняется при прокрутке списка сортов → портрет Герта Топа с четырьмя нумерованными обещаниями → фото поля + три двери (Plantgids / Bezoek / Groothandel) → FAQ → контакт на сливовом фоне → футер с крупным wordmark.
Groothandel: полноэкранное фото поля, факты, три целевые группы в линованных карточках, четыре шага, таблица размеров/наличия, партийные цены и сервисы, сливовый блок с offerte-формой и портретом контактного лица, FAQ.

## Концепция B — «Estate» (тёмный эстейт)

Наследие и статус: ночной зелёно-чёрный `#0f1412`, шампань `#f1ece3`, латунь `#cdb17c`; симметричная центрированная композиция, рамки-outline вокруг фото, золотые разделители. Шрифты **Marcellus** (римские капители) + **Figtree**. Логотип — печать «TR» с кольцевой надписью «TOP RHODODENDRONS · OTTERLO · MMI».
Главная: видео-хиро с печатью по центру и заглавным заголовком → лента фактов → утверждение → горизонтальная галерея семи сортов, которая едет при вертикальной прокрутке (на мобильном — свайп) → портрет садовода в рамке с цитатой и обещаниями → фото поля → CTA «для профессионалов» с плавающей галереей фото → FAQ → «Bezoek» с контактами → футер.
Groothandel: тёмная страница в том же языке: печать, заглавный заголовок, факты, карточки проектов, шаги, воорраад, offerte-форма, FAQ.

## Концепция C — «Veld» (современный минимализм)

Самый современный вариант: тёплый камень `#f1efea`, чернила `#141413`, олива `#3f4a37` для CTA; большие скруглённые фотоблоки (28 px), пилюли-кнопки, капсульная навигация при прокрутке. Один гротеск **Manrope**. Логотип — геометрический лист-монограмма «T» в мягком квадрате, строчный wordmark.
Главная: видео-хиро с крупным заголовком «Rhododendrons die aanslaan. Gegarandeerd.» → bento-сетка «четыре причины» с реальными фото → карточки семи сортов с ценой и tuinturf → портрет садовода с цитатой → сплит-CTA «для сада / для профессионалов» → FAQ → зелёный контакт-блок → футер.
Groothandel: скруглённый хиро-блок с пилюлями, четыре карточки-факта, проекты, шаги, таблица, оливковый блок с offerte-формой, FAQ.

## Общие правила

- Только реальные тексты и факты из старого репозитория; отзывы и «примеры проектов» не использованы. Цены — из каталога (`vanaf € … за 40–60 см`).
- Контраст AA, видимый фокус, `aria`-атрибуты меню/аккордеона, `alt` на фото, `prefers-reduced-motion`.
- 1440 и 390 px без горизонтальной прокрутки (проверено Playwright: `scrollWidth` = viewport на всех 14 видах).

## Открытые вопросы

1. Какая концепция ближе? Можно комбинировать (например, логотип из одной, структуру из другой).
2. Видео — ИИ-ролик; для продакшена лучше снять настоящее видео поля в мае (горизонтальное и вертикальное).
3. Графический логотип: три предложения в SVG — выбрать один для доработки.
4. Следующая фаза: ассортимент с фильтрами, страница сорта, корзина, plantgids, формы с отправкой почты.
